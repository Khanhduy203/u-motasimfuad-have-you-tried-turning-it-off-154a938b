One funny line a hopeless tech support agent says to a desperate customer — an entry for the [make.fun bounty "Have You Tried Turning It Off?"](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

The joke twists the classic reboot advice: the agent cheerfully "escalates" the case to the senior team — who turns out to be the same agent in a different headset — and then reaches for the reboot anyway.

## Run it

```sh
node main.ts
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`). Node standard library only, no dependencies.
